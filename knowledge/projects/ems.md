# 储能 EMS 边缘网关 · 项目说明

## 概况
- 个人作品集项目，由我一个人完成；设备是仿真，厂商名称均为虚构。演示：http://47.117.29.74:8095/ ；源码：https://github.com/rfs151/ai-ems
- 做什么：部署在储能站现场的 EMS 边缘网关：多厂商设备 Modbus 接入、功率控制（FCR / mFRR / LFSM-O）、规则告警、本地存储、MQTT 云边协同。仿真 1MW/2MWh 储能站。
- 和我工作经历的关系：对应我在江苏极光云能做的储能 EMS 边缘网关（C99、ARM aarch64 Linux）。真实项目代码不能公开，这个演示按同样的技术栈和业务重新实现，展示重点放在 C 语言网关和功率控制算法。

## 架构
- device-sim（Python）：PCS×2、电池簇×2、关口电表、DI/DO，每台设备一个 Modbus TCP 端口；电网频率信号源 = 50 Hz + 低幅噪声 + 页面注入的扰动。
- ems-core（C99、pthread，约 4000 行）：采集调度 → 实时库 → 控制器 → 下发设定值；规则引擎、告警事件、SQLite WAL 存储、104 子站、固件验签。
- ems-sync（C99 独立进程）：flock 单实例锁、MQTT TLS、从 SQLite outbox 批量取数据上云，接收下行指令校验后经 unix socket 转给 ems-core。
- ems-cloud（FastAPI）+ Vue 页面：订阅上行数据推给浏览器，把页面操作转成下行 MQTT 指令。

## 实时性与并发设计
- 采集：每台设备一个线程；快组 200 ms（功率、频率）、慢组 5 s（温度、单体电压）；连续寄存器合并成批量读；超时、断线重连、指数退避；连续失败 N 次判离线，数据带质量位。
- 实时库：点位数组 + 读写锁；控制循环通过快照接口一次性读取，变化回调通知规则引擎和存储。
- 控制：100 ms 控制周期；P_cmd = 计划 + mFRR + FCR + LFSM-O 叠加，再经 SOC 限幅、PCS 可用容量、爬坡率限制，按可用容量分配到两台 PCS。同一台 PCS 两次写设定值至少间隔 300 ms，期间变化合并。
- 告警事件：异步事件队列（环形缓冲 + 条件变量），不阻塞采集和控制线程。
- 存储：SQLite WAL + busy_timeout + (point_id, ts) 复合索引，批量事务写入，缩短锁临界区；这正是我在真实项目里解决多线程数据库锁竞争的做法。
- 规则匹配：规则加载后按触发点位排序，点位变化时二分查找命中规则；1000 条规则时二分查找 33 ns，线性查找 223 ns（网关启动时实测）；每 200 ms 一轮约 5 µs。

## 难点与解决
- **mFRR 调度轨迹**：准备（已激活、功率为 0）→ 台阶爬坡 → 保持 → 降坡；计划激活迟到但仍在准备期内照常执行，超过就拒绝；直接激活可带 0～60 秒提前量，越限被网关拒绝并返回原因；交付中再下发同向指令，从当前实际值平滑过渡，总功率不跳变。
- **LFSM-O 过频限功率**：以叠加后的当前出力为参考，ΔP = P × (f − f_start) / 50 / droop，只削减放电、最多削到 0，充电时不调整；可远程投退、改启动频率和下垂系数。
- **多厂商点表适配**：厂商差异写在 JSON 配置里（数据类型、字序、倍率、偏移、功能码），32 位整数支持 ABCD/CDAB/BADC/DCBA 四种字节序，配置写错直接报错，不静默当成大端；厂商 B 的 PCS 要先写使能字再写设定值，用少量 C 钩子处理。
- **采集容错**：某个寄存器块返回异常响应只影响这一块的点，设备不判离线；只有链路错误才断开重连。
- **断网不丢数据**：数据先写 SQLite outbox，每 1 s 或满 200 条打包上云，断网时留在 outbox，恢复后按时间顺序补传；指令带 id 和过期时间，边缘侧去重并拒绝过期指令，结果回 cmd_ack。
- **数据库原地升级**：规则表新增列时先查 pragma_table_info，老库启动时自动补列。

## 关键数据
- 144 项单元测试（控制算法 91、点位编解码 23、规则 30），可在 ASan / UBSan 下运行；mFRR 轨迹、叠加交接、FCR/LFSM-O 曲线用表驱动测试覆盖。
- 云端下发指令往返约 50 ms（本机实测）。
- 技术栈：C99、pthread、libmodbus、SQLite WAL、libmosquitto（MQTT TLS）、TinyExpr、lib60870-C（IEC 104 子站）、OpenSSL RSA-2048 + SHA256 固件验签、FastAPI、Vue。
